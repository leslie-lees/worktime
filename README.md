# worktime 打卡记录

手机 H5 页面：记录每天上/下班打卡时间，自动扣除午休 1 小时，统计是否达到 8.3 小时，累计超出/不足时间；支持请假、上传打卡原图并随时下载原图，也支持一次选择多天截图，自动识别日期和时间后批量导入。

- 页面代码：本仓库（GitHub Pages 托管）
- 数据与截图：私有仓库 `worktime-data`（`data/records.json`、`images/`、`thumbs/`），页面通过你自己的 token 读写，token 只保存在本机浏览器

## 计算规则

- 工作时长 = 下班 − 上班 − 60 分钟
- 标准 = 8.3 小时（498 分钟），≥ 标准显示「已达到」
- 累计 = 每天（工作时长 − 498 分钟）之和，不足的天数会抵扣超出时间
- 请假的日子不计入统计
